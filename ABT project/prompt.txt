6. CORE PRODUCT USP
============================================================

There are two important differentiating features.

USP 1:

INTEGRATED INTERVIEW WORKSPACE

Students and interviewers should be able to conduct interviews inside the platform using ZEGO Cloud.

Minimum functionality:

- Video
- Audio
- Participants
- Join/leave
- Interview details
- Basic interviewer notes/evaluation

Do NOT build video infrastructure from scratch.

Do NOT add:

- Recording
- Facial analysis
- Cheating detection
- AI interviewer
- Complex chat system

Verify the current ZEGO integration/API before implementation.

------------------------------------------------------------

USP 2:

AI CONFIDENTIALITY GUARD

The system checks student weekly reports for potentially confidential information before the report is shared through the internship monitoring workflow.

Possible categories:

- API keys
- Passwords
- Tokens
- Customer/personal information
- Financial/transaction information
- Internal URLs/endpoints
- Source code snippets
- Internal project/product details
- Confidential/NDA references

The AI should return structured information such as:

riskLevel:
- SAFE
- LOW
- MEDIUM
- HIGH

And:

- flaggedCategories
- flaggedItems
- suggestion

IMPORTANT:

AI only FLAGS potential confidentiality problems.

AI must NOT make the final human decision.

The student should be able to edit the report and resubmit.

The backend should handle the AI integration.

NEVER expose AI API keys in the frontend.

If the AI service is unavailable:

- Handle the failure gracefully.
- Do not falsely claim that the report was successfully checked.
- Keep the integration modular so the service can be configured later.
